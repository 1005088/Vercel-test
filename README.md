# Country Dashboard

A Next.js dashboard with an overview table and an interactive Three.js globe for three example countries.

The country names, flags, coordinates, and metric values are placeholders. Replace them with verified data before using this as a factual dashboard.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Next.js. The files and their responsibilities are described in the [`readme/`](./readme/README.md) folder.
