# File guides

These notes describe the purpose of each retained application and dependency file.

- [`app/page.md`](./page.md): navigation, overview table, country selector, and details.
- [`app/countries.md`](./countries.md): example country data, map positions, and placeholder flag colors.
- [`app/earth-globe.md`](./earth-globe.md): Three.js Earth rendering, flag markers, and globe interaction.
- [`app/layout.md`](./layout.md): root layout, global styles, and page metadata.
- [`styles.md`](./styles.md): shared dashboard and responsive styles.
- [`package.md`](./package.md): project scripts and runtime dependencies.
- [`package-lock.md`](./package-lock.md): purpose of the generated npm lockfile.
