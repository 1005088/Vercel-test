# `app/earth-globe.js`

Creates the client-side Three.js globe shown in the Countries section. It generates a small illustrative terrain texture, places a flag marker at each country's coordinates, and supports dragging to rotate the Earth.

Selecting a flag on the globe updates the dashboard's selected country. The sidebar dropdown rotates that country's marker toward the front of the globe. This is a lightweight visual model, not an authoritative geographic dataset.
